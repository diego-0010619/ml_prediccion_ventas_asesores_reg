# ml_prediccion_ventas_asesores_reg
El siguiente proyecto consta de predecir el valor de las ventas de un asesor comercial en el mes t (mes actual).  Con la ayuda de variables predictoras que caracterizan tanto a la tienda donde el asesor hizo su gestión comercial como las propias características del asesor. En cada registro hay detalles de las ventas del asesor 3 meses atrás.
